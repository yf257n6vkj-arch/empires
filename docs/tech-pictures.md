# Technology pictures

Every technology has a page in the game with room for one picture. When a picture is missing, the page shows a large drawn icon.

## Generating all pictures at once

The script `tools/generate-images.ts` sends all prompts to Google's Gemini API and saves the pictures to `src/web/techs/`. It skips finished pictures, so if a run is interrupted, just run it again. Single pictures can be regenerated with `--only`.

1. Create an API key in Google AI Studio and enable billing for the project. Image generation has no free tier.
2. Run `GEMINI_API_KEY=your-key npm run images`, either in a cloud environment that allows `generativelanguage.googleapis.com`, or on a Mac in the repository folder.
3. Then review the pictures, regenerate failed ones with `npm run images -- --only key`, commit them and publish a new version.

The prompts for the script are in `tools/image-prompts.json`; the same text for manual use follows below.

## Adding a picture by hand

Save the picture in landscape 4 : 3, ideally 1024 × 768 pixels, as `webp`, `jpg` or `png`. Name the file after the technology's key in brackets, for example `pottery.webp`, and put it in `src/web/techs/`. The game finds it on the next build.

The prompts share the same opening so that the pictures have one style. Send the generator the whole line after the colon. The prompts contain no names of real people, because some generators refuse them.
